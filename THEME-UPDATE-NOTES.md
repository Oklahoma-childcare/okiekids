# Logo-inspired website theme update

This website has been restyled around the user-provided Okie Kids logo.

- Deep teal: `#1c5660` and deep pine `#16464e`
- Sage: `#4c7867`, pale eucalyptus `#deebd7`
- Parchment: `#fdfcf7`
- Warm accent: `#a77a51`, muted ochre `#d9bb80`

The supplied logo is installed at `public/branding/logo.png` and used in navigation, footer and favicon. The social links, site information, routes, responsive layouts, and page content were preserved. The Open Graph card was adjusted to match.

Start locally with `npm install` and `npm run dev`; validate with `npm run typecheck` and `npm run build`. Prerendered HTML files are regenerated by npm scripts.
