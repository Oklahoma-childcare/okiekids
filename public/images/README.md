You can store your own approved/local image files here.

To use your own hero picture:
1. Copy a JPG to `public/images/hero.jpg`.
2. In `src/config/images.ts`, change the `hero.src` value to `/images/hero.jpg`.
3. Run `npm run build`, then redeploy.

Repeat for the other image keys. Keep the `alt` text accurate after replacement.
Do not copy photos of children from the center's social posts without permission.
