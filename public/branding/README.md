EDITABLE LOGO — 0 CODE CHANGES

Replace `public/branding/logo.png` with your own approved PNG using exactly
that filename. The header, footer, and browser tab automatically use it.
Recommended: square 600x600 or larger, transparent background.

If your actual logo is JPG or SVG, put the file here and update `logoUrl`
in `src/config/site.ts` and the `<link rel="icon">` in the generator.

`public/branding/logo.png` is a temporary, custom OK monogram until an authentic
academy logo can be sourced with permission. It is NOT their verified logo.

The `og-card.png` file is the social-sharing image; you may replace that too.
